## The problem

We had a 5.3 GB MySQL database full of base64-encoded resumes sitting in text columns.

## What changed

- Moved binary resume files to Cloudflare R2
- Normalized and cleaned up dead columns
- Migrated the schema to SQLite-compatible types for D1

## Result

Database size dropped from 5.3 GB to roughly 5 MB.
