A web app for building and browsing a personal board game collection, with user accounts, profiles and a game catalogue sourced from BoardGameGeek.

## Highlights

- Supabase authentication, profile setup and per-user game data
- BoardGameGeek XML API client with retry and back-off, parsed with `fast-xml-parser`
- Search, filters, add-game flow and an edit modal for entries
