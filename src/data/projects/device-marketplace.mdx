Full-stack assignment: a Next.js front end over an Express and MongoDB API, with sign-up, sign-in and a filterable grid of device listings.

## Highlights

- Sidebar filters for brand, condition, RAM, storage, price, warranty and verified listings
- Session-based authentication with `express-session`, bcrypt password hashing and `express-validator` input checks
- Listing model with geo-coordinates, locality and multiple images
- Client-side data fetching and state split into store, query and provider modules
